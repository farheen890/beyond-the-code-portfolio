# BEYOND THE CODE — Farheen Meti

An experimental, responsive personal portfolio built with React, TypeScript, Vite, and Lucide icons. The site emphasizes practical engineering, project status transparency, and an interest in Forward Deployed Engineering.

## Run locally
Requirements: Node.js 18+ (20+ recommended).

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite (normally http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

Production output is generated in `dist/`.

## Personalise before publishing
Edit `src/config.ts` and add only verified public details for `linkedin`, `email`, and `resume`. These are intentionally blank until provided. The project content lives in `src/App.tsx`; preserve the stated project statuses and do not add unverified results.

## Included
- Responsive React + TypeScript + Vite setup
- Dark charcoal, warm-paper, and electric-lime visual system
- Interactive project selector with keyboard-operable buttons and selected-state announcements
- Major cyber-forensics project, malware traffic classification, StreetSnackSync, and TravelOasis AI
- FDE-oriented problem-solving approach section
- Responsive navigation, visible focus states, and reduced-motion support
- SEO description and Open Graph metadata
- No external image assets required; Google Fonts are loaded remotely
